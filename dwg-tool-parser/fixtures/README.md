# dwg-tool-parser / fixtures

Committed fixtures for the DWG/DXF parser (see `../AGENTIC.md`).

## `golden_example.json`

Hand-written schema-valid example emitted in DP-2 as the canonical
target shape. Used by `tests/test_dwg_parser_schema.py` to verify that
the schema correctly accepts a known-good payload and rejects mutations
of it. Does not correspond to any real source file.

## `sample.dxf`

Small synthetic DXF generated by `ezdxf.new("R2018")` for the DP-3
round-trip. Regenerated automatically by
`tests/test_dwg_parser_ezdxf.py::TestGenerateFixture` when missing.

Contents:

- **Layers** — two TOTaLi survey layers:
  - `TOTaLi-SURV-BOUNDARY-DRAFT` (color 1)
  - `TOTaLi-SURV-MONUMENT-DRAFT` (color 2)
- **Model-space entities** — three entities matching the DP-2 golden
  spec's entity mix:
  1. `LINE` on `TOTaLi-SURV-BOUNDARY-DRAFT` from `(100, 200, 0)` to
     `(350.5, 200, 0)`.
  2. `LWPOLYLINE` on `TOTaLi-SURV-BOUNDARY-DRAFT`, closed, three
     vertices forming the three sides of a rectangle corner.
  3. `INSERT` on `TOTaLi-SURV-MONUMENT-DRAFT` referencing the
     `MON_MARKER` block at `(100, 200, 0)`.
- **Block `MON_MARKER`** — two `LINE` entities forming a `+` marker
  centered on the block origin.

The DXF is committed as a plain-text ASCII file (~16 KB) so diffs are
reviewable. Regenerating it from `_build_sample_dxf(...)` in the test
file produces a byte-for-byte-similar file modulo `ezdxf`'s handle
allocation, which does not affect the committed-schema round-trip.
